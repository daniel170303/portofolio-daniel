# Project Images

Add your project images here. Each project can have multiple images.

## Naming Convention:
- `one-gym-1.jpg`, `one-gym-2.jpg`, etc. for One Gym project
- `lika-liku-laki-1.jpg`, `lika-liku-laki-2.jpg`, etc. for Lika Liku Laki project

## Usage:
- Place images in this directory
- Update the `images` array in `app/Http/Controllers/PortfolioController.php` for each project
- Example: `'images' => ['/images/projects/one-gym-1.jpg', '/images/projects/one-gym-2.jpg']`

## Image Requirements:
- Recommended size: 800x600px or similar aspect ratio
- Format: JPG, PNG
- File size: Keep under 500KB per image for optimal loading
